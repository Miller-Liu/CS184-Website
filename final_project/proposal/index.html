Dawn to Dust: Volumetric Scattering

Website Link: miller-liu.github.io/CS184-Website/final_project/proposal/

Contributers: Miller Liu, Stephane Finot, Kevin Hu, John Bragado

Project Summary: In this project, we will be implementing ray marching to simulate volumetric scattering. The end goal will be to be able to light a morning scene through a window and highlight the atmosphere with our volumetric scattering.

Problem Description

From what we've covered in class, light is only modeled as interacting with surfaces. However, in the real world, light also interacts with the space between objects—scattering through the air, diffusing in fog, or breaking into different wavelengths when passing through certain materials. The goal of our project is to enhance realism in rendered scenes by implementing volumetric scattering, allowing us to simulate effects like atmospheric haze, light shafts, and dust-filled environments. We will solve this by implementing ray marching and sampling as a ray travels rather than only at intersections.

Goals and Deliverables

We plan to deliver scenes with basic volumetric lighting. We want to render images of scenes (like the one below) with light shining through a window or through a projector. Our project will showcase the scene with different parameters like the placement, brightness, and colors of light, as well as the density of fog.

We want to make sure that the light scattering is modeled correctly through physically correct equations, so our metrics will be to make sure we have a visual output that is similar to some industry examples, such as the Disney samples given. We are trying to provide an answer for how to effectively implement volumetric scattering. Our target is to be able to light a scene with a directed light and see the region of the scene that the light rays are traveling through.

If things go well, we would like to incorporate dust particles that float around and glow in the light. This would add even further to the immersion and create an effect that brings our scenes closer to realism. A problem that may arise is animating the paths of the dust particles.

Another ambition would be to figure out how to set the light source to mimic an image so that we could see the different colors of the image flying through the volumetric lighting (similar to a movie projector).

In addition, we hope to be able to create an interactive GUI that allows us to change certain parameters of the light, camera, and scene while rendering. However, this would require real-time rendering which would be very difficult to implement.
